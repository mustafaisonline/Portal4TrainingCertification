## 2. Learning outcomes — by the end participants can
1. Explain how organisations turn data into decisions, and what "trusted data" needs: metadata, building blocks, modelling, processing and storage, architecture, governance, quality, privacy.
2. Read and sketch an enterprise data landscape (the Data Blueprint) for their own organisation or client.
3. Explain what an LLM, RAG, an agent and a skill are, and where agentic AI fits on top of governed data.
4. Direct an AI coding agent from a written vision to a working product, using the eight-document Vibe Coding Method and a constitution file.
5. Recognise the build sequence — wireframe → physical data model → product → admin panel — and the checks between steps.
6. Name the ways vibe-coded projects fail and the rule that prevents each.
7. Leave with their own Vision.md and a first prototype started (Day 2 hands-on).
