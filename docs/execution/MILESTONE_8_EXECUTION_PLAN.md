Already delivered by earlier milestones: offerings (M4), reviews moderation (M5b), certificate administration and fee (M6).

## 1. What exists
`platform_admin` gate on `/admin` (server-side, 403 for participants); admin screens for offerings, reviews, certificates, fee; tables `orders`, `payments`, `refunds`, `registrations`, `enquiries` (status `new · replied · closed`), `users`, `user_profiles`, `user_roles` (scoped, revocation as state), `audit_log` (insert-only), `outbound_emails`. Roles `expert · assessor · org_admin` exist in the enum but have no product meaning yet. No `organisations`, `invoices` or attendance tables.

## 2. Scope (existing schema only)
1. **Admin navigation** — `src/shared/chrome/admin-nav.ts` (one source, like the site and account navs) and a sub-navigation bar in the admin layout: Overview · Offerings · Orders · Enquiries · Reviews · Certificates · Users · Audit log · Reports. The overview page becomes a status board (pending reviews, open enquiries, certificates expiring within 30 days, last reminder run, revenue this month).
2. **Orders & payments** — `/admin/orders`: list with filters (status, kind, currency, date range, search by email / order id), totals for the filtered set; `/admin/orders/[id]`: order, payment (fee, receipt link), refunds, registration and its cancellation/transfer history, certificate when a renewal, audit trail for the order. **Read-only** (see §5 A2 for the refund-on-behalf action).
3. **Enquiries** — `/admin/enquiries`: list with status filter and search; detail with the message, programme, source page; actions **Mark replied** / **Close** / **Reopen** with an audit row `enquiry.status_changed` (before/after). No email is sent from here (replies happen from the founder's mailbox; ENQUIRY_NOTIFY_EMAIL already forwards new ones to the outbox).
4. **Users & roles** — `/admin/users`: search by name/email, list with roles and registration/certificate counts; `/admin/users/[id]`: identity facts, masked profile summary (never the ID number), registrations, orders, certificates, reviews, consents, roles with history; actions **Grant platform administrator** / **Revoke** (audit `role.granted` / `role.revoked`, actor recorded; an administrator cannot revoke the last remaining administrator or themselves). Only `platform_admin` is grantable in the MVP.
5. **Audit log** — `/admin/audit`: newest first, filters by action, entity type, entity id, actor, date range; row detail shows before/after JSON read-only. Insert-only remains: no action on this screen writes anything.
6. **Reports** — `/admin/reports`: registrations per offering (confirmed / cancelled / transferred, seats), revenue by month and currency (paid orders, refunds netted, processing fees where known), certificates (issued, active, renewal due, expired, revoked), reviews by moderation state, enquiries by status. Server-computed from the tables; CSV download of each table via a route handler (no library — hand-written CSV with proper quoting).
7. **Participant data export (PDPA access right, M5 leftover)** — `/account/profile` gains "Download my data": `GET /api/me/export` returns a JSON file of the person's own records (account, profile with the ID number **masked** as on screen, registrations, orders, payments, refunds, reviews, certificates, renewals, consents, and audit rows where they are the actor). Session-gated, `Cache-Control: no-store`, audited as `profile.exported`.
8. **Tests** — integration for every action and computation, e2e for each screen with a participant refused, axe on every new page.

## 4. Verification criteria
1 every admin screen returns 403 to a participant and 200 to an administrator · 2 grant/revoke writes the role row and the audit row in one transaction; last-admin and self-revoke refused · 3 enquiry status changes audited with before/after · 4 report numbers equal direct SQL on fixture data · 5 CSV opens with correct quoting of commas/quotes/newlines · 6 export contains only the caller's rows and no plaintext ID number; another user's id in the query is ignored · 7 audit screen writes nothing · 8 axe clean; tsc · Vitest · Playwright · build.
