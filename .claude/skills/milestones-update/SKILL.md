---
name: milestones-update
description: Update framework/milestones.md when a milestone is achieved or its status changes. Use after a milestone completes or when verifying milestone status.
---

Read the milestone's own plan/completion report or the CR tracker first; change a row only on evidence and cite it. Keep statuses to NOT STARTED / IN PROGRESS / DONE / DEPLOYED / BLOCKED. Update `docs/execution/PROJECT_STATUS.md` in the same change if the milestone table there is affected. Rows marked "confirm in plan §status" must be verified before changing.
