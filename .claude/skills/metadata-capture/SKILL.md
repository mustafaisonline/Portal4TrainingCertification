---
name: metadata-capture
description: Create a metadata .md file (business, technical or operational) for a table, view, script, policy, procedure, contract or definition. Use to document any item.
---

1. Pick the category (see `framework/metadata/README.md`). 2. Read the source of truth (schema, script, document). 3. Copy `framework/metadata/_TEMPLATE.md` to `framework/metadata/<category>/<kind>-<name>.md` and fill it from the source; do not guess. 4. Add a row to the category README index. Documentation only: change no code or data.
